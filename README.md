# Local Work Manager

로컬 브라우저에서만 저장되는 개인 업무 관리 툴입니다.

## 사용 방법

1. `index.html` 파일을 브라우저로 엽니다.
2. 업무, 하위 업무, 피드백, 캘린더 반복 체크를 등록합니다.
3. 데이터는 사용 중인 브라우저의 LocalStorage에 저장됩니다.

## 포함 기능

- 업무 대시보드: 시간내서 할 것, 시간나면 할 것, 보류, 완료함
- 업무 준 사람 태그별 색상 구분
- 상위/하위 업무 및 각각의 마감일 관리
- 하위 업무 정렬: 등록일 최신순, 같은 등록일이면 마감일 빠른순
- 캘린더 보기와 반복 체크
- 피드백 메모 및 카테고리 태그
- CSV 내보내기

## 주의

이 앱은 서버 없이 로컬에서 동작합니다. GitHub에 올라가는 것은 앱 파일뿐이며,
사용자가 브라우저에 저장한 실제 업무 데이터는 포함되지 않습니다.
